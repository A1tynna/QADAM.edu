# MyQadam LMS

Полноценный учебный портал для подготовительной школы: авторизация, три пользовательские роли, расписание, электронный журнал, учебные материалы и объявления.

## Возможности

- **Администратор:** создаёт, блокирует и удаляет пользователей; составляет расписание; публикует объявления; видит все данные школы.
- **Учитель:** видит своё расписание; выставляет и удаляет оценки; загружает PDF, презентации, документы, архивы и внешние ссылки.
- **Ученик:** регистрируется с раздельным выбором номера и буквы класса; видит расписание своего класса, личные оценки, материалы и адресованные ему новости.
- **Самостоятельная регистрация:** можно выбрать роль ученика или учителя; адрес подтверждается шестизначным кодом из письма. Роль администратора самостоятельно выбрать нельзя.
- **Защита аккаунта:** пароль должен содержать не менее 10 символов, заглавную и строчную буквы, цифру и специальный символ; пробелы запрещены.
- JWT-сессии, хеширование паролей, проверка ролей на API, адаптивный интерфейс и начальные демонстрационные данные.

## Настройка подтверждения почты

Регистрация отправляет настоящие письма через SMTP. Создайте `.env` на основе `.env.example` и заполните параметры почтового ящика:

```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=your-account@gmail.com
SMTP_PASS=your-app-password
SMTP_FROM="MyQadam <your-account@gmail.com>"
```

Для Gmail включите двухэтапную аутентификацию и создайте отдельный **пароль приложения** — обычный пароль аккаунта использовать не следует. `.env` исключён из Git и не попадёт в репозиторий или Docker-образ.

Код подтверждения действует 15 минут. Повторное письмо можно запросить через 60 секунд; после пяти неверных попыток необходимо запросить новый код. Без заполненного SMTP регистрация корректно блокируется и сообщает, что почтовая служба не настроена.

## Быстрый запуск через Docker

```bash
docker compose up --build
```

Откройте публичный лендинг: [http://localhost:3000](http://localhost:3000).

Вход и регистрация в учебном портале: [http://localhost:3000/portal](http://localhost:3000/portal).

## Локальный запуск

1. Запустите PostgreSQL:

   ```bash
   docker compose up -d db
   ```

2. Установите зависимости и запустите приложение:

   ```bash
   npm install
   npm start
   ```

Сервер автоматически создаёт и обновляет таблицы, а при первом запуске добавляет демонстрационные данные. Настройки базы и почты задаются переменными из `.env.example`.

## Проверка

При запущенных сервере и базе:

```bash
npm run check
npm test
```

Smoke-тест проверяет вход для всех ролей, права доступа и CRUD-сценарии расписания, журнала, материалов, объявлений и пользователей, удаляя созданные тестовые записи после проверки.

## Совместная разработка и автоматический деплой

Рабочий процесс для разработчиков:

1. Создать ветку от актуальной `main`.
2. Внести изменения и открыть Pull Request.
3. Дождаться успешного workflow `Test and deploy production` и проверки кода.
4. После merge в `main` GitHub Actions автоматически обновит VPS и проверит `https://myqadam.kz/api/health`.

Для deployment job используются repository secrets `MYQADAM_DEPLOY_KEY` и `MYQADAM_KNOWN_HOSTS`. Приватный SSH-ключ не должен храниться в Git, `.env`, сообщениях или документации. На VPS ключ ограничен принудительной командой `/usr/local/sbin/deploy-myqadam` и не предоставляет интерактивный доступ к серверу.
